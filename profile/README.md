# Origin Intel

**Authority-based intelligence platform for monitoring the cryptocurrency ecosystem.**

Origin Intel tracks high-signal activity across developers, governance forums, and social platforms to surface early indicators, systemic risks, and emerging narratives.

---

## What Origin Intel Does

- Monitors authoritative actors across crypto ecosystems
- Detects anomalous events and narrative shifts
- Links related activity across projects and platforms
- Prioritizes signals using adaptive intelligence pipelines

---

## High-Level Architecture

> This is a conceptual overview. Implementation details may evolve.

- **Backend**: Python, FastAPI, Celery
- **Data Layer**: PostgreSQL, Redis
- **Frontend**: Next.js 14, Tailwind CSS, shadcn/ui
- **Mobile**: React Native with push notifications
- **AI Pipeline**:
  - Lightweight models for fast triage
  - Heavy models for deep contextual analysis
- **Data Sources**:
  - X (Twitter)
  - GitHub
  - Governance platforms (Snapshot, Tally)

---

## Core Systems

1. **Authority Graph Builder**  
   Maps and scores authoritative entities across platforms.

2. **Monitoring Engine**  
   Adaptive polling optimized for rate limits and signal density.

3. **Triage Pipeline**  
   Multi-stage classification pipeline:
   - Pattern-based filters
   - Lightweight ML models
   - Deep reasoning models

4. **Anomaly Detection**  
   Baseline behavior tracking with deviation alerts.

5. **Context Engine**  
   Connects events across time, projects, and ecosystems.

6. **Learning System**  
   Continuously improves from user feedback.
